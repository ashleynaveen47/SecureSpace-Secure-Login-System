# 🔐 SecureSpace – Secure Login System

SecureSpace is a secure user authentication web application
developed using Python Flask, SQLite, HTML and CSS.

It provides user registration, login authentication and
secure session management with a modern responsive interface.

## 🚀 Features

- User Registration
- Secure Login Authentication
- Password Hashing
- SQLite Database Integration
- CSRF Protection
- Session Management
- Login Rate Limiting
- Secure Logout
- Responsive User Interface

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Werkzeug

## ⚙️ Installation

1. Clone the repository.

2. Install dependencies:

pip install -r requirements.txt

3. Run the application:

python app.py

4. Open your browser:

http://127.0.0.1:5000
